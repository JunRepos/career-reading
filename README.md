# 진로 독서 프로젝트

신동고 2학년 진로 수업(2-1 ~ 2-6)의 진로 독서 프로젝트 사이트입니다.
https://junrepos.github.io/career-reading/

## 학생
- 진로 수업 사이트(ai-career)와 같은 **학번 · 비밀번호**로 들어갑니다. 반은 학번에서 알아냅니다 (20321 → 2-3반).
- 홈 — 내 책, 지금 할 일과 남은 날, 우리 반 일정
- ① 진로 독서 활동지 (1~2차시) — 종이 활동지와 같은 칸. 종이로 낸 것은 선생님이 옮겨 적은 내용이 채워져 있고 학생이 고칠 수 있습니다.
- ② 최종 소감문 — 선생님이 열면 씁니다.
- 마감이 지나도 낼 수 있고, 늦게 낸 것으로 표시됩니다.

## 선생님
- 진로 수업 사이트의 선생님 비밀번호로 들어갑니다.
- 반별 현황 — 학생마다 책 · 활동지 · 소감문 상태. 활동지에 9월과 다른 책을 적었으면 「다른 책」 으로 표시
- 반별 일정 — 대여일 · 1·2차시 · 활동지 마감 · 반납일 · 최종 소감문 완성일 · 소감문 열기. 「여섯 반 모두 이 날짜로」
- 학생 한 명 — 책 고치기, 활동지 · 소감문 고치기, 종이 여부 · 제출일 넣기, 처음 판독한 내용과 비교
- 엑셀로 내려받기 (CSV)

## 데이터
수업앱과 같은 Firebase. `aiactivity/submissions/{반}/reading/` 아래에 저장합니다 (자세히는 `js/config.js` 머리말).
학생 계정은 `students/{반}`, 9월에 고른 책은 `aiactivity/submissions/{반}/actCareerRead01` 을 읽습니다.
**학생 글은 이 레포에 두지 않습니다.**

종이 활동지는 스캔을 손글씨 판독해 `source: 'paper'` 로 넣고, 판독 원문은 `ocr` 에 따로 남겨 고친 뒤에도 비교할 수 있게 합니다.
